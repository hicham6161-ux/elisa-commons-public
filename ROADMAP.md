# Roadmap

## v0.5 — current reference implementation

- local SQLite memory;
- portable owner profile;
- selective owner-state export;
- encrypted portable bundles;
- local/remote model endpoint classification;
- exact capability grants;
- evidence / contradiction / abstention states;
- hash-linked provenance ledger;
- governed tool proxy;
- skill quarantine and explicit human approval;
- bounded local reads;
- deterministic migration tests.

## v0.6 — next

- revocable and expiring grants;
- typed tool manifests;
- stable/versioned owner-bundle schema;
- local model/runtime discovery;
- encrypted recovery workflow;
- CLI coverage and hardening;
- external-user migration fixtures.

## v0.7 — interoperability

- open-agent orchestration adapters;
- open search/retrieval adapters;
- reviewed skill ecosystem adapters;
- richer receipt/provenance interoperability;
- cross-platform packaging.

## v1.0 criteria

- stable public interfaces;
- documented migration compatibility;
- external testers/contributors;
- independent security review;
- cross-platform reference demo;
- conformance corpus.
